## Avant de poster

1. **Lis les règles de chaque subreddit le jour même** (barre latérale et
   wiki). Elles changent, et beaucoup limitent l'autopromotion : jour
   dédié, « flair » obligatoire, ratio de participation, ancienneté du
   compte, interdiction pure et simple. Les textes de `reddit.md` ne
   remplacent pas cette lecture. En cas de doute, écris aux modérateurs
   avant de poster.
2. **Un post par communauté, pas le même copié partout**, et pas tous le
   même jour : le multi-post identique est traité comme du spam.
3. **Dis que c'est ton projet.** Ne te fais pas passer pour un utilisateur.
4. **Reste pour répondre.** Un post d'outil sans réponse aux commentaires
   est mal vu ; prévois d'être disponible les heures qui suivent.
5. **Remplace les éléments entre crochets** (`[lien]`, `[capture]`) et
   vérifie que le lien de téléchargement pointe vers la release publiée.

## Ce que les textes disent, et ne disent pas

Ils décrivent ce que l'application fait réellement aujourd'hui :

- **Windows uniquement** (10 et 11). Ne pas écrire « multiplateforme ».
- **Projet personnel**, récent. Ne pas écrire « utilisé par des milliers
  de serveurs ».
- **L'Agent IA est en bêta**, désactivé par défaut : ne pas en faire
  l'argument principal.
- **« Open source »** : le dépôt n'a pas encore de fichier `LICENSE`. Tant
  qu'il n'y en a pas, le code est public mais pas open source au sens
  strict — les textes disent donc « code source sur GitHub ». Si tu
  ajoutes une licence (MIT, GPL…), tu pourras remplacer par
  « open source » et viser aussi r/opensource.
- **Outils tiers** : Playit.gg, Geyser, Modrinth, CurseForge, AuthMe sont
  des projets indépendants ; l'app les installe ou les utilise, elle ne
  les a pas créés. Les textes le disent ainsi.
- **Assistance IA** : si le code a été écrit avec l'aide d'une IA et que
  la communauté demande de le signaler (certaines le font), dis-le.
